National University Grading & GPA

Understand how this viewer presents grade points and GPA information. Start a result search from NU Results.

Honours grade-point mapping

For Honours results, the viewer uses the course credits and letter grades parsed from the NU result response when a supported response contains those fields. The resulting credit-weighted GPA is presented as a calculated value in the result view.

Degree Pass GPA

Degree Pass result sheets may contain a GPA supplied by National University, including year-specific labels such as GPA (2nd Year). When NU provides a GPA, this viewer displays that value directly.

The viewer does not invent or recalculate a Degree Pass GPA.

Master's result values

Master's and Preliminary to Master's responses are displayed from the fields returned by the National University result service. Where a response contains CGPA, GPA or course grades, the viewer presents those returned values rather than treating an inferred value as an official record.
